# AI Fluency Labs

Each lab lives in its own folder:

- [Day 1: Agentic AI Foundations](day1/README.md) compares a chatbot, a rule-based workflow, and an AI agent.
- [Day 2: Reasoning Techniques](day2/README.md) explores chain-of-thought, self-consistency, and ReAct.
- [Day 3: ReAct Agent Failure Modes](day3/README.md) builds an agent with tools, then adds loop, output-size, and budget guards.

Install dependencies from the lab you want to run with `pip install -r requirements.txt` inside that lab's folder. Day 2 and Day 3 import shared agent configuration from `day1`.
